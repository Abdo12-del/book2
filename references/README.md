# سجل المراجع التراكمي — «المتحدث الصغير: من التأسيس إلى التأثير»

> **الغرض:** قاعدة معرفية دائمة يُبنى عليها تأليف الكتاب، بحيث لا نعيد البحث من الصفر
> عند كتابة أي فصل. هذا المجلد **ليس** محتوى الكتاب، وليس تصميم صفحاته.

## ١. كيف يُحفظ هذا السجل فعليًا (بلا ادّعاءات)

| الوسيلة | الحالة | ملاحظة |
|---|---|---|
| ملفات داخل المستودع (`references/`) | ✅ **فعليّة ودائمة** | تُحفظ في مساحة العمل وتُرفع إلى Git في كل تحديث |
| Git (commits على الفرع) | ✅ **فعليّة ودائمة** | كل دفعة مصادر = commit مستقل قابل للرجوع إليه |
| ذاكرة المحادثة | ⚠️ **ليست وسيلة حفظ موثوقة** | لا تعتمد عليها؛ المرجع الوحيد هو هذه الملفات |

**القاعدة:** أي معلومة لا توجد في ملف داخل `references/` تُعتبر **غير محفوظة**.

## ٢. بنية المجلد

```
references/
├── README.md            ← هذا الملف: المنهجية والقواعد
├── register.yaml        ← السجل التراكمي (بيانات كل مصدر + ربطه بالفهرس)
├── coverage.md          ← مصفوفة التغطية (يُولَّد آليًا: أي فصل بلا مرجع؟)
├── proposals.md         ← «مقترحات تحتاج إلى اعتماد» (لا تُضاف للمنهج إلا بقرار)
└── sources/
    ├── _template.md     ← قالب الملف التفصيلي لكل مصدر
    └── S001.md …        ← ملف تحليلي مستقل لكل مصدر
```

## ٣. حقول السجل (`register.yaml`)

| الحقل | المعنى |
|---|---|
| `id` | رمز المصدر (S001…) |
| `origin` | **`user`** = زوّدتني به · **`agent`** = وجدته ببحثي المستقل (تمييز إلزامي) |
| `part` | الباب المرتبط (١–٤) كما حدّدته أنت |
| `type` | كتاب / بحث محكّم / دليل تدريبي / تقرير مؤسسي / مقال / مادة مرئية |
| `title` `author` `translator` `publisher` `year` `edition` `isbn` | البيانات الببليوغرافية |
| `language` | ar / en / fr |
| `url` | رابط مباشر إلى المصدر أو نسخته القانونية |
| `access` | `full` = النص كاملاً متاح · `partial` = فصول محددة · `metadata-only` = بيانات فقط · `none` |
| `access_note` | ما تعذّر الوصول إليه بالضبط (أمانةً لا تجميلاً) |
| `reliability` | **علمي محكّم** / مهني موثوق / خبرة عملية / رأي المؤلف |
| `summary` | موضوع المصدر في سطرين |
| `key_ideas` | الأفكار والمبادئ القابلة للاستفادة (بصياغتي، لا نسخًا) |
| `mapping` | الربط بالفهرس: رقم الفصل + أرقام العناصر + سبب الربط |
| `quotes_to_verify` | اقتباسات/معلومات تحتاج توثيقًا دقيقًا (نص + صفحة + حالة التحقق) |
| `cross_source` | اتفاق/اختلاف/تكامل مع مصادر أخرى بالرمز |
| `value_for_trainer` | كيف يتحوّل هذا إلى شرح أو نشاط أو معيار تقييم للمدرب |
| `open_questions` | ما يحتاج تحققًا إضافيًا |

## ٤. قواعد ملزمة (مستقاة من توجيهاتك)

1. **لا نسخ:** الأفكار تُعاد صياغتها بأسلوب أصلي يناسب المدرب العربي؛ النص الطويل لا يُنقل.
2. **لا اختراع:** لا أرقام صفحات، ولا اقتباسات، ولا بيانات ببليوغرافية إلا مما تحقّقت منه فعليًا.
   وما لم أتمكن من فتحه يُسجَّل `access: metadata-only` مع بيان السبب.
3. **فصل الطبقات:** يُميَّز دائمًا بين (ما قاله المصدر) و(استنتاجي/اقتراحي).
4. **لا إضافة تلقائية للمنهج:** كل فكرة جديدة تُوضع في `proposals.md` بانتظار الاعتماد.
5. **الربط بالباب فقط:** لا يُنقل أثر مصدر إلى باب آخر إلا بصلة واضحة **مع تسجيل سبب الربط**.
6. **التعريب الواعي:** المفاهيم الأجنبية تُنقل إلى السياق العربي وسياق الطفل دون تحريف معناها.

## ٥. الأوامر

```bash
python3 tools/refs.py stats                 # ملخّص السجل
python3 tools/refs.py coverage              # إعادة توليد مصفوفة التغطية
python3 tools/refs.py add new-sources.yaml  # إضافة مصادر + تحقّق من البيانات
python3 tools/refs.py show S001             # عرض مصدر واحد
python3 tools/refs.py gaps --part 2         # فجوات باب محدّد
```

## ٦. قيود بيئة العمل (مُختبرة فعليًا — لا تُخفى)

| القدرة | الحالة |
|---|---|
| البحث في الويب (`web_search`) | ✅ يعمل |
| فتح صفحة المصدر للتحقق (`fetch_page`) | ✅ يعمل |
| الشبكة المباشرة من الطرفية (curl/wget) | ❌ محجوبة إلا لمضيفين محدودين (GitHub / npm / PyPI) |
| قراءة ملف PDF يصل إلى مساحة العمل | ✅ متاحة (PyMuPDF) — بشرط نجاح وصول الملف |
| **وصول ملفاتك المرفوعة إلى البيئة** | ⚠️ **فشل في محاولة سابقة** (ملف الفهرس لم يصل) — الأنسب: لصق النص، أو مشاركة رابط، أو رفع ملف PDF داخل المستودع |
