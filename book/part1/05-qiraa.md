# الفصل الخامس: القراءة التعبيرية

القراءة التعبيرية ليست قراءة جميلة؛ إنها **قراءة تُوصِل المعنى**. والفرق بينهما مهم: فقد يقرأ الطفل بطلاقة وسرعة ونطق سليم ولا يفهم السامع شيئًا، لأنه قرأ كلمات لا معاني.

::: note القاعدة الحاكمة لهذا الفصل
**الفهم قبل الأداء.** لا يُطلب من الطفل أن يُحسّن أداءه في نص لم يفهمه. لهذا يأتي العنصر الأول في هذا الفصل عن الفهم، وتُبنى عليه كل العناصر التالية.

**والقاعدة الثانية:** القراءة التعبيرية **ليست سباق سرعة**. الطلاقة ثلاثة أشياء معًا: الدقة، والمعدل المناسب، والتعبير الصوتي. من قرأ سريعًا بلا تعبير لم يبلغ الطلاقة.
:::

## ١. فهم النص قبل أدائه

**الفكرة.** الطفل الذي لا يفهم النص يقرأه كسلسلة أصوات، ويستحيل عليه أن يُعبّر عنه. لذلك تُقسم كل جلسة قراءة إلى مرحلتين لا تُدمجان: **قراءة للفهم**، ثم **قراءة للأداء**.

::: tip كيف تشرحه للطفل
«سنقرأ النص مرتين. المرة الأولى لتفهم، والمرة الثانية لتُسمِع. في المرة الأولى لا نهتم بجمال الصوت، نهتم بأن تفهم: من يتكلم؟ وماذا يحدث؟ وماذا يشعر؟»
:::

**أسئلة الفهم الخمسة — قبل أي أداء:**

| السؤال | ماذا يكشف |
|---|---|
| من يتكلم في هذا النص؟ | المتكلم والشخصيات |
| ماذا يحدث؟ | الحدث |
| أين ومتى؟ | السياق |
| ماذا تشعر الشخصية؟ | المشاعر (وهي مفتاح الأداء) |
| ما أهم جملة؟ | مركز المعنى |

**خطوات التدريب.**

1. **اقرأ أنت النص أولًا قراءة معبّرة.** سماع النموذج شرط لإنتاجه.
2. **يقرأ الطفل قراءة صامتة أو همسية** للفهم.
3. **أسئلة الفهم الخمسة** — ولا تنتقل قبل الإجابة عنها.
4. **استراتيجية «فكّر بصوت عالٍ»:** تعلن أمام الطفل ما تفعله («أنا الآن أبطّئ لأن هذه الجملة مهمة») — فيتعلم أن الأداء قرار، لا موهبة.
5. **ثم يبدأ الأداء.**

::: warning خطأ شائع
الانتقال إلى تقويم الأداء مباشرة بعد أول قراءة. هذا يجعل الطفل يركّز على صوته لا على المعنى، فتتحول القراءة إلى استعراض صوتي.
:::

**مؤشر التقدّم.** يجيب الطفل عن الأسئلة الخمسة، ويحدد الجملة الأهم في النص قبل أن يؤديه.

## ٢. الطلاقة وسلامة النطق

**الفكرة.** الطلاقة ثلاثة أبعاد معًا: **الدقة** (نطق الكلمات صحيحة)، و**المعدل المناسب** (لا بطيء متقطع ولا سريع مبتلع)، و**التعبير الصوتي**. وإغفال أي بُعد يُنتج قراءة ناقصة.

والأداة الأهم هنا — وهي مستقرة في أدبيات تعليم القراءة (كما عند Rasinski في *The Fluent Reader*) — هي **إعادة قراءة النص نفسه**، لا الانتقال إلى نص جديد عند كل خطأ.

::: tip كيف تشرحه للطفل
«القراءة مثل الرياضة: لا تصير أقوى بلعبة جديدة كل يوم، بل بإعادة التمرين نفسه حتى يُتقن. سنقرأ هذا النص ثلاث مرات، وفي كل مرة سيتحسن شيء.»
:::

**القراءات الثلاث — لكل واحدة هدف واحد:**

| القراءة | الهدف | ما لا تهتم به |
|---|---|---|
| الأولى | الدقة: نطق الكلمات صحيحة | السرعة والتعبير |
| الثانية | المعدل: بلا توقف ولا تسرّع | التعبير |
| الثالثة | التعبير: النبر والوقف | الأخطاء البسيطة |

**خطوات التدريب.**

1. **النمذجة أولًا:** تقرأ فقرة، ثم يقرأها الطفل.
2. **القراءة الثنائية:** تقرأان معًا، فيحمل صوتك الطفل المتعثر.
3. **تسجيل الكلمات الصعبة** في قائمة صغيرة تُعاد في كل جلسة.
4. **لا تُصحّح كل كلمة أثناء القراءة.** دوّنها وصحّحها بعدها؛ المقاطعة تكسر الفهم.

::: note تنبيه لغوي للمدرب العربي
سلامة النطق هنا تعني **مخارج الحروف** (لا سيما ما يختلط منها عند الأطفال) و**الحركات** في حدود ما يناسب المرحلة. لا تتحول إلى درس تجويد أو إعراب؛ المطلوب وضوح يُفهم.
:::

::: warning خطأ شائع
**قياس القراءة بالسرعة.** المؤقّت في يد المدرب يحوّل القراءة إلى سباق، والسباق يقتل التعبير. إن استخدمت المؤقّت فليكن لملاحظة التقدّم الشخصي للطفل، لا للمقارنة.
:::

**مؤشر التقدّم.** يقرأ الطفل النص نفسه في المرة الثالثة بأخطاء أقل وبتوقفات أقل وبمعدل أنسب من المرة الأولى.

## ٣. الوقف والوصل

**الفكرة.** الوقف هو أهم أداة تعبيرية يملكها الطفل، وأسهلها تدريبًا. الطفل المتعجل يصل الجمل كلها فيصير كلامه لاهثًا؛ والطفل المتردد يقف في مواضع خاطئة فينقطع المعنى.

**القاعدة:** الوقف يكون عند **نهاية المعنى**، لا عند نفاد النفس.

::: tip كيف تشرحه للطفل
«الوقفة مثل النقطة في الطريق: تقف حيث ينتهي المعنى، لا حيث ينتهي نفَسك. وإذا احتجت أن تتنفس في منتصف جملة، فخذ نفسًا سريعًا وأكمل — لا تقف وقفة طويلة.»
:::

**أنواع الوقف الثلاثة:**

| الوقف | موضعه | مدّته |
|---|---|---|
| **قصير** | بين الجمل القصيرة، وعند الفاصلة | نصف ثانية |
| **متوسط** | نهاية الفقرة أو الفكرة | ثانية |
| **طويل** | قبل جملة مهمة — لشدّ الانتباه | ثانية ونصف |

**خطوات التدريب.**

1. **علّم الوقف بصريًا:** ضع علامات على النص ( / للقصير، // للمتوسط) ودرّبه عليها.
2. **لعبة «أين تقف؟»:** تقرأ جملة بلا وقفات، ويحدد الأطفال المواضع الصحيحة.
3. **تمرين التنفس:** نفَس من البطن قبل كل فقرة — لا من الصدر.
4. **الوقفة المقصودة:** اجعل الطفل يقف وقفة طويلة قبل أهم جملة، فيرى أثرها في السامعين.

::: warning خطأ شائع
اعتبار الوقف ترددًا ومحاولة ملئه. الوقفة الصامتة **أداة**، والفراغ فيها مقصود. درّب الطفل على أن يصمت بثبات لا أن يقول «آآآ».
:::

**مؤشر التقدّم.** يقف الطفل عند نهاية المعنى، ويستخدم وقفة طويلة مقصودة مرة واحدة على الأقل في النص.

## ٤. مراعاة علامات الترقيم

**الفكرة.** علامات الترقيم هي **نوتة الموسيقى** في النص: تخبر القارئ أين يقف، وأين يرفع صوته، وأين يُظهر دهشة. والطفل الذي يتجاهلها يقرأ نصًا بلا معنى.

::: tip كيف تشرحه للطفل
«هذه العلامات ليست زينة، إنها تعليمات لك. النقطة تقول: قف. الفاصلة تقول: خذ نفسًا قصيرًا. علامة الاستفهام تقول: ارفع صوتك في آخر الجملة. وعلامة التعجب تقول: أظهر دهشتك.»
:::

**أربع علامات تكفي هذه المرحلة:**

| العلامة | ماذا تفعل | مثال |
|---|---|---|
| **النقطة (.)** | وقفة كاملة، ونزول الصوت | «رجعتُ إلى البيت.» |
| **الفاصلة (،)** | وقفة قصيرة، والصوت يبقى معلّقًا | «أخذتُ حقيبتي، وخرجتُ.» |
| **الاستفهام (؟)** | رفع الصوت في آخر الجملة | «أين ذهبتَ؟» |
| **التعجب (!)** | طاقة أعلى، وإظهار شعور | «يا لها من قطة!» |

**خطوات التدريب.**

1. **لعبة «اقرأ العلامة»:** تقرأ جملة بصوتين مختلفين، ويختار الأطفال العلامة المناسبة.
2. **لعبة «أضف العلامة»:** نص بلا علامات، يضعونها، ثم يقرؤون.
3. **قراءة النص نفسه بعلامات مختلفة:** «رجعت إلى البيت» بنقطة وبتعجب — فيسمع الطفل الفرق بنفسه.

::: warning خطأ شائع
تعليم العلامات بوصفها قواعد إملائية تُكتب، لا إشارات تُؤدّى. **العلامة تُسمع لا تُعرف.**
:::

**مؤشر التقدّم.** يغيّر الطفل صوته بحسب العلامة، ويرفع صوته في السؤال ويُظهر الدهشة في التعجب دون تنبيه.

## ٥. التنغيم والنبر

**الفكرة.** التنغيم هو ارتفاع الصوت وانخفاضه عبر الجملة، والنبر هو **تثقيل كلمة بعينها**. وهما ما يحوّل الجملة نفسها من خبر إلى سؤال إلى دهشة.

::: tip كيف تشرحه للطفل
«الكلمة التي تُشدّد عليها هي الكلمة الأهم. اسمع الفرق: **أنا** أكلتُ التفاحة (لا غيري) · أنا **أكلتُ** التفاحة (لم أرمها) · أنا أكلتُ **التفاحة** (لا الموزة). ثلاث معانٍ مختلفة من جملة واحدة.»
:::

**خطوات التدريب.**

1. **تمرين النبر المتحرك:** جملة من أربع كلمات، ينقل الطفل النبر من كلمة إلى أخرى، ويشرح السامعون الفرق.
2. **تمرين الجملة الواحدة بثلاثة مشاعر:** الجملة نفسها تُقال فرحًا، وحزنًا، ودهشة.
3. **تعليم النبر بصريًا:** ضع خطًا تحت الكلمة المهمّة في النص.
4. **الاستماع أولاً:** تقرأ بنبر وبلا نبر، ويميّز الأطفال.

::: warning خطأ شائع
المبالغة في التنغيم حتى تصير القراءة تمثيلًا مصطنعًا. **الهدف وضوح المعنى، لا الاستعراض.**
:::

**مؤشر التقدّم.** يضع الطفل النبر على الكلمة الأهم في الجملة، ويتنوع ارتفاع صوته عبر الفقرة.

## ٦. التعبير عن معاني النص ومشاعره

**الفكرة.** هنا تلتقي كل العناصر السابقة في شيء واحد: أن **يشعر السامع** بما في النص. والشرط الأول أن يشعر القارئ نفسه؛ فالطفل الذي لا يتأثر لا يُؤثّر.

::: tip كيف تشرحه للطفل
«قبل أن تُقرأ، اسأل نفسك: ما الشعور في هذه الفقرة؟ فرح؟ خوف؟ حزن؟ ثم اقرأ وأنت تحمل هذا الشعور. لا تُظهر شعورًا لا تحسّ به، بل ابحث عن الشعور الحقيقي في النص.»
:::

**خطوات التدريب.**

1. **حدّد الشعور مع الطفل** قبل الأداء (امتداد للعنصر ١).
2. **اربط الشعور بالجسد والصوت:** الحزن — صوت أخفض وأبطأ · الفرح — أعلى وأسرع · الخوف — وقفات أكثر.
3. **تمرين «اقرأ الشعور»:** فقرة واحدة تُقرأ بثلاثة مشاعر مختلفة.
4. **اسأل السامعين:** «ماذا شعرتم؟» — فإن لم يصلهم الشعور فالأداء لم ينجح.

::: note حدّ مهم
لا تطلب من الطفل أن يُظهر شعورًا لا يفهمه. إن كان النص عن حزن لم يعرفه الطفل، فاشرح الموقف لا الشعور، واترك الأداء بسيطًا صادقًا.
:::

**مؤشر التقدّم.** يؤدي الطفل النص بشعور مناسب يصل إلى السامعين، ويُسمّيه.

## ٧. قراءة الحوارات وتمييز الشخصيات

**الفكرة.** الحوار في النص فرصة تدريبية غنية: فهو يجبر الطفل على **تغيير صوته** بين المتحدثين، وهذا تدريب مباشر على التنويع الصوتي (وهو ما سيحتاجه في الفصل السادس).

::: tip كيف تشرحه للطفل
«كل شخصية لها صوت. لا تقلّد صوتًا غريبًا، بل غيّر شيئًا واحدًا: السرعة، أو الارتفاع، أو الطريقة. وأهم شيء: اجعل السامع يعرف من يتكلم دون أن تقرأ اسمه.»
:::

**ثلاثة متغيّرات فقط تكفي لتمييز شخصية:**

| المتغيّر | مثال |
|---|---|
| **السرعة** | شخصية متحمسة — أسرع |
| **الارتفاع** | شخصية كبيرة — أخفض |
| **الإيقاع** | شخصية مترددة — وقفات أكثر |

**خطوات التدريب.**

1. **النمذجة:** تقرأ الحوار بصوتين معلنين ما تفعله («غيّرت صوتي لأن المتكلم تغيّر»).
2. **القراءة الثنائية:** تقرأ شخصية ويقرأ الطفل الأخرى.
3. **التدريج:** شخصية واحدة ثم شخصيتان ثم ثلاث.
4. **اختبار السامع:** «من المتكلم الآن؟» دون قراءة الاسم.

::: warning خطأ شائع
أن يقلّد الطفل أصواتًا مجهِدة (صراخ، خشونة متعمدة). هذا يُتعب الصوت. **التغيير في الإيقاع والسرعة لا في الضغط.**
:::

**مؤشر التقدّم.** يميّز الطفل شخصيتين على الأقل بصوته، ويعرف السامع المتكلم دون اسمه.

## ٨. تقويم القراءة التعبيرية

**الفكرة.** يُقاس هذا الفصل بخمسة معايير، ويُراعى فيها التوازن: فالقراءة السريعة الخالية من التعبير ليست طلاقة، والقراءة المعبّثة المليئة بالأخطاء ليست أداءً.

::: note ورقة تقويم الفصل الخامس (علّم الخانة بقلمك)
| المعيار | لم يتحقق | يبدأ | تحقق |
|---|---|---|---|
| يفهم النص قبل أدائه |  |  |  |
| ينطق الكلمات بدقة |  |  |  |
| معدل قراءته مناسب (لا سباق) |  |  |  |
| يقف عند نهاية المعنى |  |  |  |
| يراعي علامات الترقيم |  |  |  |
| ينوّع النبر والتنغيم |  |  |  |
| يصل شعور النص إلى السامع |  |  |  |
| يميّز أصوات الشخصيات |  |  |  |

**مهم:** لا تُقاس القراءة التعبيرية بالسرعة أبدًا. إن ظهر في الورقة أن السرعة معيار فقد فسدت الورقة.
:::

**طرق التقويم.**

1. **التسجيل قبل وبعد:** دقيقة من النص نفسه في أول الدورة وآخرها. الفرق يُسمع ولا يحتاج شرحًا.
2. **تقويم السامعين:** «هل فهمتم؟ ماذا شعرتم؟» — وهو المقياس الأدق.
3. **ملاحظة واحدة لكل قراءة:** «وقفتك عند الفواصل كانت ممتازة. المرة القادمة نجرب النبر على الكلمة المهمة.»
4. **إشراك الطفل:** «أي جزء كان الأفضل في قراءتك؟»

::: warning خطأ شائع
تصحيح النطق والتنغيم والشعور في قراءة واحدة. **ملاحظة واحدة في كل مرة**، وتُوزَّع الملاحظات على الجلسات.
:::

**مؤشر التقدّم (على مستوى الفصل كله).** يقرأ الطفل نصًا من نصف صفحة، يفهمه ثم يؤديه بوقفات ونبر وشعور يصل إلى السامعين، دون سباق مع الزمن.
