# تحليل الفهرس المعتمد — «دورة المتحدث الصغير»

> **آخر تحديث:** بعد **التعديل ١** (حذف الباب الأول: الأسس التربوية والمنهجية).
> سجل التعديلات الكامل في `docs/fihris-changelog.md`.
> **حالة هذا المستند:** تحليل وتوصية. **لا يقترح أي تعديل إضافي على الفهرس.**
> كل ما ورد تحت «ملاحظات» هو **مقترح معلّق** لا يُطبَّق إلا بقرار صريح.
> المصدر الجاري محفوظ حرفيًا في `book/fihris.txt`، والخريطة الآلية في `docs/structure-map.yaml`.

**الأرقام الجارية:** ٣ أبواب · ١٨ فصلًا · **١٣٩ عنصرًا فرعيًا** · ٨ ملاحق.

## ١. بطاقة الكتاب كما وردت في الفهرس

| البند | النص المعتمد |
|---|---|
| **العنوان** | دورة المتحدث الصغير |
| **العنوان الفرعي** | من التأسيس إلى التأثير ✅ |
| **الوصف** | دليل المدرب لتعليم مهارات التحدث للأطفال من خلال مستويين متكاملين |
| **تمهيد المنهج** | مستويان: الأول يبني أساس المتحدث، والثاني يعلّمه توظيف مهاراته في أنواع مختلفة من التواصل. كل مستوى ٨ محاور = ١٦ محورًا تدريبيًا |

**التحقق:** «٨ محاور لكل مستوى» مطابق تمامًا (المستوى الأول = الفصول ١–٨، والثاني = ٩–١٦). ✅

## ٢. البنية الكاملة (كما وردت بعد التعديل ١)

```
الباب الأول: المستوى الأول — بناء المتحدث                    (٨ فصول · ٥٩ عنصرًا)
   الفصل ١: بناء الثقة بالنفس                                          (٧)
   الفصل ٢: التعبير المباشر                                            (٧)
   الفصل ٣: بناء الرصيد اللغوي                                         (٨)
   الفصل ٤: تنظيم الحديث                                               (٧)
   الفصل ٥: القراءة التعبيرية                                          (٨)
   الفصل ٦: الأداء الصوتي                                              (٧)
   الفصل ٧: التواصل غير اللفظي                                         (٧)
   الفصل ٨: التعبير الإبداعي                                           (٨)

الباب الثاني: المستوى الثاني — المتحدث المؤثر                 (٨ فصول · ٦٤ عنصرًا)
   [تمهيد الباب] هذا المستوى لا يعيد تعليم الطفل الثقة أو الصوت أو لغة الجسد؛
                بل يستخدمها داخل مواقف تواصل لها أهداف محددة.
   الفصل ٩: التحدث التفسيري — الشرح                                    (٨)
   الفصل ١٠: التحدث الوصفي — رسم الصور بالكلمات                        (٨)
   الفصل ١١: التحدث السردي — رواية الأحداث والقصص                      (٨)
   الفصل ١٢: التحدث الحواري — إدارة الحوار والمقابلات                  (٨)
   الفصل ١٣: التحدث الإقناعي — عرض الرأي والدفاع عنه                   (٨)
   الفصل ١٤: التحدث المعلوماتي — نقل الأخبار والتقارير                 (٨)
   الفصل ١٥: التحدث الاستجابي — الإجابة والمناقشة                      (٨)
   الفصل ١٦: التحدث الارتجالي — التفكير والتعبير دون إعداد مسبق        (٨)

الباب الثالث: التطبيق والتقويم                                (فصلان · ١٦ عنصرًا)
   الفصل ١٧: توظيف مهارات التحدث في مواقف واقعية                       (٨)
   الفصل ١٨: تقويم المتحدث ومتابعة تطوره                               (٨)

الملاحق التطبيقية                                                  (٨ ملاحق)
   ١ بنك الأسئلة المباشرة والإبداعية
   ٢ بطاقات مواقف الشرح والوصف والسرد
   ٣ بطاقات الحوار والمقابلات
   ٤ موضوعات مناسبة للتدريب على الإقناع
   ٥ سيناريوهات الأخبار والتقارير
   ٦ بطاقات الأسئلة المفاجئة والارتجال
   ٧ نماذج تقييم المدرب
   ٨ نماذج تقارير أولياء الأمور
```

**فحص آلي:** لا قفز في ترقيم الفصول (١…١٨ متصل)، لا قفز في ترقيم العناصر داخل أي فصل،
لا عنوان مكرَّر حرفيًا.

## ٣. منطق البناء بعد الحذف

```
        بناء (ف١-٨)          →          توظيف (ف٩-١٦)        →     تتويج وتقويم (ف١٧-١٨)
   ┌─────────────────────┐       ┌─────────────────────┐       ┌────────────────────┐
   │   المستوى الأول     │       │   المستوى الثاني    │       │  التطبيق والتقويم  │
   │   بناء المتحدث      │  ──▶  │  المتحدث المؤثر     │  ──▶  │                    │
   │                     │       │                     │       │                    │
   │  أدوات المتحدث:     │       │  أنواع التواصل:     │       │  مواقف واقعية      │
   │  ثقة · تعبير · رصيد │       │  شرح · وصف · سرد    │       │  + تقويم شامل      │
   │  تنظيم · قراءة·صوت  │       │  حوار · إقناع       │       │  + تقارير أولياء   │
   │  جسد · خيال         │       │  معلومات · استجابة  │       │                    │
   │                     │       │  ارتجال             │       │                    │
   └─────────────────────┘       └─────────────────────┘       └────────────────────┘
        يبني المهارة               يوجّهها لغاية                 يثبّتها ويقيسها
```

**تنبيه بنيوي بالغ الأهمية بعد الحذف:** لم يبق في الفهرس ما يقدّم للمدرب
**الإطار المنهجي** (الفئة العمرية وخصائصها، نواتج التعلم، فلسفة المنهج) ولا
**منهجية التدريب والتقويم** (التدرج من النموذج إلى الأداء المستقل، التغذية
الراجعة، التقييم القبلي/التكويني/الختامي) — وهي مفاهيم **يفترضها** الفصل ١٨
(تقويم المتحدث) افتراضًا. راجع المقترح في ٧٫١.

## ٤. فهمي لطبيعة الكتاب (وصفة العمل التحريرية)

| البند | التحديد |
|---|---|
| **القارئ** | المدرب/الأستاذ — لا الطفل |
| **سؤال كل درس** | ماذا أفهم؟ كيف أشرحه؟ كيف أدربهم؟ كيف أعرف أنهم تقدّموا؟ |
| **ما ليس هو** | ليس كتاب طفل، ولا كرّاسة أنشطة، ولا ملخّصًا تسويقيًا |
| **وحدة العمل الحقيقية** | **العنصر الفرعي** (١٣٩ وحدة)، لا الفصل |
| **نبرة الخطاب** | مهني واضح: المفهوم ← مبرّره التربوي ← مثال من واقع الطفل ← خطوات التقديم ← أخطاء شائعة ← مؤشرات |
| **نمط الاستعمال** | رجوع سريع قبل الحصة (مسح بصري) لا قراءة متسلسلة |

## ٥. خريطة التحويل: من الفهرس إلى كتاب

| عنصر الفهرس | عنصر الكتاب | النمط | في الفهرس؟ | المعالجة البصرية |
|---|---|---|---|---|
| الباب (٣) | **فاصل باب** | Part | نعم | صفحة افتتاحية: اسم الباب + تمهيده + قائمة فصوله |
| الفصل (١٨) | **فصل** | Heading 1 | نعم | يبدأ صفحة فردية جديدة + رقمه بالحروف كما ورد |
| العنصر (١٣٩) | **وحدة تعليمية** | Heading 2 | نعم | عنوان مرقّم داخل الفصل + مسافة قبل واضحة |
| محتوى الوحدة | أهداف/شرح/مثال/عبارات/خطوات/تنبيه/مؤشر | Heading 3 عند الحاجة + صناديق | **لا** | صناديق ملوّنة وظيفية |
| الملاحق (٨) | **ملحق** | Heading 1 (بلا ترقيم فصل) | نعم | ترقيم (ملحق ١…٨) + جدول ربط بالفصول |

**قواعد التحويل:** صفر تعديل تلقائي · الترقيم كما ورد · «محور» مصطلح تربوي لا عنوان ·
رمز الإحالة المقترح `(الفصل-العنصر)` مثل `(٤-٤)` · كل ملاحظة تُعرض ولا تُنفَّذ إلا بقرار.

## ٦. معالجة محتوى الوحدة التعليمية

العناصر التسعة تُبنى كـ**أنماط جاهزة للاستدعاء**، تُستخدم حيث تناسب، ولا تُدرج كعناوين جديدة:

`هدف الدرس` · `المفهوم والمهارة` · `الشرح التربوي` · `مثال من واقع الطفل` ·
`نماذج عبارات وأسئلة` · `خطوات التقديم والتدريب` · `أخطاء شائعة` ·
`مؤشرات التقدّم` · `فروق فردية`

## ٧. ملاحظات هيكلية (مقترحات معلّقة — لا تُطبَّق دون موافقة)

### ٧.١ فجوة الإطار المنهجي (ناتجة عن الحذف) — **الأهم**
بعد حذف الباب الأول لا يوجد موضع يشرح للمدرب: خصائص الفئة العمرية، نواتج التعلم،
التدرج من النموذج إلى الأداء المستقل، التغذية الراجعة، وأنواع التقييم —
وهي مفاهيم يستخدمها الفصل ١٨ افتراضًا.
> **المقترح (لا يُغيّر الفهرس):** نقل العناصر الاثني عشر المحذوفة إلى **تمهيد غير مرقّم**
> في صدر الكتاب («كيف تستخدم هذا الدليل» + «الإطار المنهجي الموجز»). تحفظ المادة
> بلا إضافة باب أو فصل. **بانتظار قرارك.**

### ٧.٢ فصول لا يُختم عناصرها بـ«تقويم»
الفصول: **٣، ٦، ٧** و**٩–١٥، ١٧** تفتقد عنصر تقويم، مقابل ١، ٢، ٤، ٥، ٨، ١٦، ١٨.
> **المقترح:** صندوق «مؤشرات التقويم» غير مُفهرَس في نهاية كل فصل، يُستقى من
> معايير الفصل ١٨ — فيتوحّد الإيقاع بلا إضافة عنوان واحد.

### ٧.٣ نمط الخاتمة غير موحّد في المستوى الثاني
الفصول ٩–١٥ تُختم بـ«تطبيقات: …» والفصل ١٦ بـ«تقويم سرعة توليد الأفكار».
> **المقترح:** توحيد **المعالجة البصرية** للخاتمة (صندوق تطبيقات / صندوق تقويم) لا النص.

### ٧.٤ تقاطعات تحتاج توضيح الحدود (لا دمجًا)

| الموضعان | التقاطع | المعالجة المقترحة |
|---|---|---|
| ١-٤ «التعريف بالنفس» ↔ ٢-١ «التعبير عن الذات» | تقديم النفس فعلُ ثقة مقابل تعبير عن محتوى | سطر «حدود هذا الدرس» + إحالة |
| ٣-٦ «أدوات الربط وإبداء الرأي» ↔ ٤-٤ «أدوات الربط بين الأفكار» ↔ ١٣-٣ «بناء الحجة» | أدوات الربط في ثلاثة مواضع | تمييز النطاق: ربط كلمات / ربط أفكار / ربط حجج |
| ٥-٥ «التنغيم والنبر» ↔ ٦-٣ «تنويع النبرة» ↔ ٦-٤ «التعبير الصوتي عن المشاعر» | التنغيم في قراءة النص مقابل الكلام العفوي | إحالة متبادلة |
| ٢-٦ «من الإجابة إلى الحديث القصير» ↔ ٨-١ «من الإجابة إلى إنتاج الأفكار» | **أقرب موضع إلى التكرار اللفظي** | توضيح الغاية: حديث قصير مقابل توليد أفكار |
| ٨ «التعبير الإبداعي/بناء قصة» ↔ ١١ «السرد/رواية الأحداث» | إنتاج المادة الخيالية مقابل بنيتها السردية | تمييز صريح في مقدمة كل فصل |
| ١٥ «الاستجابي» ↔ ١٦ «الارتجالي» | كلام بلا إعداد: إجابة عن سؤال مقابل بناء حديث من محفّز | سطر تمييز في أول كل فصل |
| ٧-٧ «الحضور أمام الكاميرا» ↔ ١٧-٦ «تقديم موضوع أمام الكاميرا» ↔ ١٧-٧ | اكتساب المهارة مقابل توظيفها | إحالة فقط |

### ٧.٥ الملاحق وربطها بالفصول
> **المقترح:** جدول ربط في صدر قسم الملاحق:
> م١ ↔ ٢، ١٥، ١٦ · م٢ ↔ ٩، ١٠، ١١ · م٣ ↔ ١٢، ١٥ · م٤ ↔ ١٣ ·
> م٥ ↔ ١٤ · م٦ ↔ ١٥، ١٦ · م٧ ↔ ١٨ · م٨ ↔ ١٨
> **تنبيه:** الملحق ٧ (نماذج تقييم المدرب) كان يرتبط أيضًا بفصل «منهجية التقويم»
> المحذوف — فإن لم يُعتمد مقترح ٧٫١، وجب أن يتضمن الملحق ٧ شرحًا مصغرًا لمنهجية التقويم.

### ٧.٦ لا توجد تجهيزات كتاب (أمامية وخلفية)
> **المقترح:** إضافتها كتجهيزات لا كأبواب منهج: `كيف تستخدم هذا الدليل` ·
> `ثبت المصطلحات` · `فهرس الموضوعات` (مهم في مرجع يتجاوز ٢٠٠ صفحة) ·
> `قائمة الجداول والأشكال` إن وُجدت.

### ٧.٧ حجم الكتاب المتوقع — **قرار مطلوب قبل النموذج الأولي**

| الكثافة | صفحات الوحدة | الإجمالي التقديري (١٣٩ وحدة) |
|---|---|---|
| موجزة | ~١ صفحة | ~١٩٠–٢٢٥ صفحة |
| متوازنة | ~١٫٥–٢ صفحة | ~٢٦٠–٣٢٠ صفحة |
| موسّعة | ~٢٫٥–٣ صفحات | ~٣٨٠–٤٥٠ صفحة |

## ٨. ما أحتاجه للانتقال إلى النموذج الأولي

1. **تأكيد القرارين المعلّقين:** ترقيم الفصول ١–١٨ (المطبَّق) أم الأرقام الأصلية؟
   ومصير العناصر الاثني عشر المحذوفة (حذف نهائي أم تمهيد غير مرقّم؟).
2. **قرار الكثافة (٧٫٧)** وعدد الصفحات المستهدف.
3. **قياس الصفحة** (A5 / B5 / A4 / مخصص).
4. **الخطوط** (Amiri + Noto Sans Arabic / Noto Naskh / خط توفرّه).
5. **الفئة العمرية ومدة الجلسة وعدد جلسات الدورة.**
6. **عمق فهرس المحتويات:** ثلاثة مستويات (١٣٩ مدخلًا) أم مستويان؟
7. **أي مادة موجودة** للدورة أبني عليها بدل الإنشاء.
