# تحليل الفهرس المعتمد — «دورة المتحدث الصغير»

> **حالة هذا المستند:** تحليل وتوصية. **لا يحتوي أي تعديل على الفهرس.**
> كل ما ورد تحت «ملاحظات» هو **مقترح معلّق** لا يُطبَّق إلا بقرار صريح.
> المصدر الأصلي محفوظ حرفيًا في `book/fihris.txt`، والخريطة الآلية في `docs/structure-map.yaml`.

---

## ١. بطاقة الكتاب كما وردت في الفهرس

| البند | النص المعتمد |
|---|---|
| **العنوان** | دورة المتحدث الصغير |
| **العنوان الفرعي** | من التأسيس إلى التأثير ✅ (مؤكَّد في الفهرس كما أوردته) |
| **الوصف** | دليل المدرب لتعليم مهارات التحدث للأطفال من خلال مستويين متكاملين |
| **تمهيد المنهج** | مستويان: الأول يبني أساس المتحدث، والثاني يعلّمه توظيف مهاراته في أنواع مختلفة من التواصل. كل مستوى ٨ محاور = ١٦ محورًا تدريبيًا |

**نتيجة التحقق:** العبارة «٨ محاور لكل مستوى» مطابقة تمامًا للوارد
(المستوى الأول = الفصول ٣–١٠، والمستوى الثاني = الفصول ١١–١٨). ✅

## ٢. البنية الكاملة (كما وردت، بلا تغيير)

```
الباب الأول: الأسس التربوية والمنهجية                        (فصلان · ١٢ عنصرًا)
   الفصل ١: الإطار العام للمنهج                                        (٦)
   الفصل ٢: منهجية التدريب والتقويم                                    (٦)

الباب الثاني: المستوى الأول — بناء المتحدث                   (٨ فصول · ٥٩ عنصرًا)
   الفصل ٣: بناء الثقة بالنفس                                          (٧)
   الفصل ٤: التعبير المباشر                                            (٧)
   الفصل ٥: بناء الرصيد اللغوي                                         (٨)
   الفصل ٦: تنظيم الحديث                                               (٧)
   الفصل ٧: القراءة التعبيرية                                          (٨)
   الفصل ٨: الأداء الصوتي                                              (٧)
   الفصل ٩: التواصل غير اللفظي                                         (٧)
   الفصل ١٠: التعبير الإبداعي                                          (٨)

الباب الثالث: المستوى الثاني — المتحدث المؤثر                 (٨ فصول · ٦٤ عنصرًا)
   [تمهيد الباب] هذا المستوى لا يعيد تعليم الطفل الثقة أو الصوت أو لغة الجسد؛
                بل يستخدمها داخل مواقف تواصل لها أهداف محددة.
   الفصل ١١: التحدث التفسيري — الشرح                                   (٨)
   الفصل ١٢: التحدث الوصفي — رسم الصور بالكلمات                        (٨)
   الفصل ١٣: التحدث السردي — رواية الأحداث والقصص                      (٨)
   الفصل ١٤: التحدث الحواري — إدارة الحوار والمقابلات                  (٨)
   الفصل ١٥: التحدث الإقناعي — عرض الرأي والدفاع عنه                   (٨)
   الفصل ١٦: التحدث المعلوماتي — نقل الأخبار والتقارير                 (٨)
   الفصل ١٧: التحدث الاستجابي — الإجابة والمناقشة                      (٨)
   الفصل ١٨: التحدث الارتجالي — التفكير والتعبير دون إعداد مسبق        (٨)

الباب الرابع: التطبيق والتقويم                               (فصلان · ١٦ عنصرًا)
   الفصل ١٩: توظيف مهارات التحدث في مواقف واقعية                       (٨)
   الفصل ٢٠: تقويم المتحدث ومتابعة تطوره                               (٨)

الملاحق التطبيقية                                                  (٨ ملاحق)
   ١ بنك الأسئلة المباشرة والإبداعية
   ٢ بطاقات مواقف الشرح والوصف والسرد
   ٣ بطاقات الحوار والمقابلات
   ٤ موضوعات مناسبة للتدريب على الإقناع
   ٥ سيناريوهات الأخبار والتقارير
   ٦ بطاقات الأسئلة المفاجئة والارتجال
   ٧ نماذج تقييم المدرب
   ٨ نماذج تقارير أولياء الأمور
```

**الإجمالي:** ٤ أبواب · ٢٠ فصلًا · **١٥١ عنصرًا فرعيًا** · ٨ ملاحق.
**فحص آلي:** لا قفز في ترقيم الفصول (١…٢٠ متصل)، لا قفز في ترقيم العناصر داخل أي فصل،
لا عنوان مكرَّر حرفيًا.

## ٣. منطق البناء التربوي كما أفهمه

```
   تأصيل            بناء              توظيف             تتويج وتقويم
 ┌──────────┐   ┌─────────────┐   ┌─────────────┐   ┌──────────────┐
 │ الباب ١  │──▶│  الباب ٢    │──▶│  الباب ٣    │──▶│   الباب ٤    │
 │ الأسس    │   │ المستوى ١   │   │ المستوى ٢   │   │ التطبيق      │
 │ والمنهجية│   │ بناء المتحدث│   │ المتحدث     │   │ والتقويم     │
 │ (ف ١-٢)  │   │  (ف ٣-١٠)   │   │ المؤثر      │   │  (ف ١٩-٢٠)   │
 │          │   │             │   │  (ف ١١-١٨)  │   │              │
 │ للمدرب   │   │ أدوات       │   │ أنواع       │   │ مواقف واقعية │
 │ نفسه     │   │ المتحدث     │   │ التواصل     │   │ + تقويم شامل │
 └──────────┘   └─────────────┘   └─────────────┘   └──────────────┘
   يعرف          يبني              يوجّه              يثبّت ويقيس
   الإطار        المهارة           المهارة            الأثر
```

- **الباب الأول** موجّه للمدرب نفسه: الفلسفة، الأهداف، خصائص النمو، نواتج التعلم، دوره.
- **الباب الثاني** يبني **أدوات** المتحدث (الثقة، التعبير، الرصيد اللغوي، التنظيم،
  القراءة التعبيرية، الصوت، لغة الجسد، الخيال) — تسلسل من الداخل إلى الخارج.
- **الباب الثالث** يوظّف تلك الأدوات في **أنواع تواصل** محددة الهدف (شرح، وصف، سرد،
  حوار، إقناع، معلومات، استجابة، ارتجال) — وهنا معنى «المتحدث المؤثر».
- **الباب الرابع** يجمعها في مواقف واقعية ثم يقيس الأثر ويوثّقه.

**القاعدة الحاكمة للكتابة:** كل درس في البابين الثاني والثالث يُقرأ بوصفه
«مهارة + سياق استعمالها»، لا بوصفه معلومة. والبابان الأول والرابع هما الإطار
الذي يُفهم به البابان الأوسطان ويُقاس به أثرهما.

## ٤. فهمي لطبيعة الكتاب (وصفة العمل التحريرية)

| البند | التحديد |
|---|---|
| **القارئ** | المدرب/الأستاذ — لا الطفل |
| **السؤال الذي يجيب عنه كل درس** | ماذا أفهم؟ كيف أشرحه؟ كيف أدربهم؟ كيف أعرف أنهم تقدموا؟ |
| **ما ليس هو** | ليس كتاب طفل، ولا كرّاسة أنشطة، ولا ملخّصًا تسويقيًا |
| **وحدة العمل الحقيقية** | **العنصر الفرعي** (١٥١ وحدة)، لا الفصل |
| **نبرة الخطاب** | مهني واضح: المفهوم ← مبرّره التربوي ← مثال من واقع الطفل ← خطوات التقديم ← أخطاء شائعة ← مؤشرات |
| **نمط الاستعمال** | رجوع سريع قبل الحصة (Scanning) لا قراءة متسلسلة — وهذا يفرض تصميمًا قابلًا للمسح البصري |

## ٥. خريطة التحويل: من الفهرس إلى كتاب (دون إخلال بالمنهج)

| عنصر الفهرس | عنصر الكتاب | النمط | في فهرس المحتويات؟ | المعالجة البصرية |
|---|---|---|---|---|
| الباب (٤) | **فاصل باب** | Part | نعم (سطر مميّز) | صفحة افتتاحية: اسم الباب + تمهيده + قائمة فصوله |
| الفصل (٢٠) | **فصل** | Heading 1 | نعم | يبدأ صفحة جديدة (فردية) + رقم الفصل بالحروف كما ورد |
| العنصر (١٥١) | **وحدة تعليمية** | Heading 2 | نعم | عنوان مرقّم داخل الفصل + مسافة قبل واضحة |
| محتوى الوحدة | **طبقة مساعدة** (أهداف/شرح/مثال/عبارات/خطوات/تنبيه/مؤشر) | Heading 3 عند الحاجة + صناديق | **لا** | صناديق ملوّنة وظيفية — لا تُضاف إلى الفهرس |
| الملاحق (٨) | **ملحق** | Heading 1 (بلا ترقيم فصل) | نعم | ترقيم (ملحق ١…٨) + جدول ربط بالفصول |

**قواعد التحويل الملتزم بها:**

1. **صفر تعديل تلقائي** على العناوين أو ترتيبها أو عددها.
2. **الترقيم كما ورد:** الفصول متصلة ١–٢٠ (لا تُعاد لكل باب)، والعناصر مرقّمة داخل فصلها.
3. **كلمة «محور» لا تُستحدث كعنوان:** التمهيد يسمّي فصول المستويين محاور، لكن الفهرس
   لا يستخدمها تسميةً للعناوين؛ سأبقيها مصطلحًا تربويًا في الشرح، وأبقي العناوين
   على أسمائها الواردة (باب/فصل).
4. **أرقام الإحالة الداخلية** المقترحة: `(الفصل-العنصر)` مثل `(٦-٤)` — لأحالات
   دقيقة داخل مرجع طويل (مقترح، يحتاج موافقة).
5. **كل ملاحظة هيكلية** تُعرض في قسم (٧) أدناه ولا تُنفَّذ إلا بقرار.

## ٦. معالجة محتوى الوحدة التعليمية (كما طلبتَ: إرشاد لا قالب)

العناصر التسعة التي ذكرتها تُبنى كـ**أنماط جاهزة للاستدعاء**، تُستخدم حيث تناسب
كل درس، ولا تُدرج كعناوين جديدة في الفهرس:

`هدف الدرس` · `المفهوم والمهارة` · `الشرح التربوي` · `مثال من واقع الطفل` ·
`نماذج عبارات وأسئلة` · `خطوات التقديم والتدريب` · `أخطاء شائعة` ·
`مؤشرات التقدّم` · `فروق فردية`

## ٧. ملاحظات هيكلية (مقترحات معلّقة — لا تُطبَّق دون موافقة)

### ٧.١ فصول لا يُختم عناصرها بـ«تقويم»
الفصول: **٥، ٨، ٩** (في المستوى الأول) و**١١–١٧، ١٩** تفتقد عنصر تقويم،
بينما ٣، ٤، ٦، ٧، ١٠، ١٨، ٢٠ تتضمنه.
> **الاحتمال الراجح:** التقويم مُجمَّع عمدًا في الفصل ٢ (منهجية التقويم) والفصل ٢٠ (تقويم المتحدث).
> **المقترح (لا يغيّر الفهرس):** إضافة **صندوق «مؤشرات التقويم»** غير مُفهرَس في نهاية كل
> فصل، يُستقى من معايير الفصلين ٢ و٢٠ — فيتوحّد إيقاع الفصول بلا إضافة عنوان واحد.

### ٧.٢ نمط الخاتمة غير موحّد في المستوى الثاني
الفصول ١١–١٧ تُختم بـ«تطبيقات: …»، والفصل ١٨ يُختم بـ«تقويم سرعة توليد الأفكار».
> **المقترح:** الإبقاء على النص كما هو، وتوحيد **المعالجة البصرية** للخاتمة
> (صندوق تطبيقات / صندوق تقويم) لا النص.

### ٧.٣ تقاطعات تحتاج توضيح الحدود (لا دمجًا)
| الموضعان | التقاطع | المعالجة المقترحة |
|---|---|---|
| ٣-٤ «التعريف بالنفس» ↔ ٤-١ «التعبير عن الذات» | تقديم النفس فعلُ ثقة مقابل تعبير عن محتوى | سطر «حدود هذا الدرس» + إحالة |
| ٥-٦ «أدوات الربط وإبداء الرأي» ↔ ٦-٤ «أدوات الربط بين الأفكار» ↔ ١٥-٣ «بناء الحجة» | أدوات الربط مذكورة ثلاث مرات | تمييز النطاق: ربط الكلمات / ربط الأفكار / ربط الحجج |
| ٧-٥ «التنغيم والنبر» ↔ ٨-٣ «تنويع النبرة» ↔ ٨-٤ «التعبير الصوتي عن المشاعر» | التنغيم في قراءة النص مقابل الكلام العفوي | إحالة متبادلة |
| ٤-٦ «من الإجابة إلى الحديث القصير» ↔ ١٠-١ «من الإجابة إلى إنتاج الأفكار» | **أقرب موضع إلى التكرار اللفظي** | توضيح الغاية: حديث قصير مقابل توليد أفكار |
| ١٠ «التعبير الإبداعي/بناء قصة» ↔ ١٣ «السرد/رواية الأحداث» | إنتاج المادة الخيالية مقابل بنيتها السردية | تمييز صريح في مقدمة كل فصل |
| ١٧ «الاستجابي» ↔ ١٨ «الارتجالي» | كلاهما كلام بلا إعداد: إجابة عن سؤال مقابل بناء حديث من محفّز | سطر تمييز في أول كل فصل |
| ٩-٧ «الحضور أمام الكاميرا» ↔ ١٩-٦ «تقديم موضوع أمام الكاميرا» ↔ ١٩-٧ | اكتساب المهارة مقابل توظيفها | إحالة فقط |

### ٧.٤ الملاحق بلا ربط بالفصول
> **المقترح:** **جدول ربط** في صدر قسم الملاحق (لا عناوين جديدة):
> م١ ↔ فصول ٤، ١٧، ١٨ · م٢ ↔ ١١، ١٢، ١٣ · م٣ ↔ ١٤، ١٧ · م٤ ↔ ١٥ ·
> م٥ ↔ ١٦ · م٦ ↔ ١٧، ١٨ · م٧ ↔ ٢، ٢٠ · م٨ ↔ ٢٠

### ٧.٥ غياب تجهيزات الكتاب (أمامية وخلفية) — ليست من المنهج
لا يوجد في الفهرس: مقدمة، ولا «كيف تستخدم هذا الدليل»، ولا ثبت مصطلحات، ولا فهرس موضوعات.
> **المقترح:** إضافتها **كتجهيزات كتاب لا كأبواب منهج**، وبموافقتك:
> `كيف تستخدم هذا الدليل` (خريطة قراءة للمدرب) · `ثبت المصطلحات` ·
> `فهرس الموضوعات` (مهم جدًا في مرجع يتجاوز ٢٠٠ صفحة) · `قائمة الجداول والأشكال` إن وُجدت.

### ٧.٦ حجم الكتاب المتوقع — **قرار مطلوب قبل النموذج الأولي**
١٥١ وحدة تعليمية. تقدير المدى:

| كثافة المعالجة | صفحات الوحدة | الإجمالي التقديري |
|---|---|---|
| موجزة | ~١ صفحة | ~٢٠٠–٢٤٠ صفحة |
| متوازنة | ~١٫٥–٢ صفحة | ~٢٨٠–٣٤٠ صفحة |
| موسّعة (كل العناصر التسعة في كل درس) | ~٢٫٥–٣ صفحات | ~٤٠٠–٤٨٠ صفحة |

هذا القرار يحدّد كثافة التصميم، وقياس الصفحة، وعمق الفهرس — لذا يُحسم قبل النموذج.

## ٨. ما أحتاجه للانتقال إلى «النموذج الأولي»

1. **إجابة ملاحظات ٧٫١ و٧٫٥** (صندوق تقويم لكل فصل؟ تجهيزات الكتاب؟).
2. **قرار الكثافة (٧٫٦):** موجزة / متوازنة / موسّعة — وعدد الصفحات المستهدف إن وُجد.
3. **قياس الصفحة** (A5 / B5 / A4 / مخصص).
4. **الخطوط** (المقترح المُختبَر: Amiri متن + Noto Sans Arabic عناوين / Noto Naskh / خط تُوفّره).
5. **الفئة العمرية ومدة الجلسة وعدد جلسات الدورة** (تضبط عمق الأمثلة وطول الوحدة).
6. **عمق فهرس المحتويات:** ٣ مستويات (باب/فصل/وحدة = ١٥١ مدخلًا، ~٥ صفحات)
   أم مستويان (باب/فصل فقط)؟
7. **أي مادة موجودة** للدورة (دليل مدرب، عروض، أوراق عمل) أبني عليها بدل الإنشاء.
