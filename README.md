# دليل منهج الكاتب الصغير

دليل عملي للميسّرين والمعلمين والأسر، يرافق الطفل من الحكاية وتوليد الفكرة إلى بناء القصة وكتابتها ومراجعتها ومشاركتها.

## محتوى الدليل

يضم الدليل ثماني وحدات متدرجة ضمن أربعة مستويات، وخطة تنفيذ من 16 لقاءً، ونموذج قصة مشروحًا، وأوراق عمل قابلة للطباعة، وأدوات للتقويم والتمايز، ومراجع علمية.

الفهرس الهرمي يضم الوحدات والعناوين الفرعية مع أرقام الصفحات، وتدعم علامات التنقل الوصول السريع إلى أقسام الدليل في نسخة PDF. يمكن تكييف زمن اللقاءات والأنشطة بحسب عمر الأطفال وخبرتهم.
